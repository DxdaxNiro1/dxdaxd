# Proyecto Android Studio 3.2

Abre la carpeta con `settings.gradle.kts`, usando JDK 17 y SDK 34. Sincroniza y ejecuta `gradlew.bat :app:assembleDebug`. El APK queda en `app/build/outputs/apk/debug/app-debug.apk`.

La versión es 33 / 3.2, con mínimo API 19 y GLES2. Conserva el identificador y la firma anteriores para actualizar manteniendo el guardado. No se incluyen SDK local ni claves personales. Consulta `LEEME.md`, `DETALLES_3_2.md`, `RECORRIDO_3_2.md` y `RENDIMIENTO_3_2.md`.
