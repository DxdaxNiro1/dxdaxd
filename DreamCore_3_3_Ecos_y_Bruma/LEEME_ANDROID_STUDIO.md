# Proyecto Android Studio 3.3

Abre `settings.gradle.kts` con JDK 17 y SDK 34. Sincroniza y ejecuta `gradlew.bat :app:assembleDebug`. El APK queda en `app/build/outputs/apk/debug/app-debug.apk`.

Versión 34 / 3.3, mínimo API 19 y GLES2. Conserva identificador y firma de tu aplicación existente para actualizar la partida. No se incluyen SDK local ni claves personales. Lee LEEME.md y ECOS_Y_BRUMA_3_3.md.
