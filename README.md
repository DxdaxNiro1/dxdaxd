Para investigar: Ajustes → Rutas y destinos → El pueblo. Para reducir trabajo: Ajustes → Energía → Fresco. La protección automática conserva los modelos, materiales y efectos, y puede reducir resolución cuando Android comunica calor. No hay mediciones físicas de temperatura, consumo o FPS.

Extrae el ZIP y ejecuta Instalar_Windows.cmd sobre tu proyecto; se crea una copia de seguridad. Instala el APK con tu misma clave e identificador para mantener el guardado. El proyecto completo se abre desde DreamCore en Android Studio. SDK 34 / JDK 17 o compatible / minSdk 21.
