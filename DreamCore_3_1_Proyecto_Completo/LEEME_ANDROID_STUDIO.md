# Proyecto Android Studio 3.1

Abre la carpeta que contiene `settings.gradle.kts`, con JDK 17 y SDK 34. Sincroniza Gradle y ejecuta `gradlew.bat :app:assembleDebug`. El resultado queda en `app/build/outputs/apk/debug/app-debug.apk`.

Para actualizar una instalación existente conserva su identificador y firma; la versión de esta entrega es 32 / 3.1 y el mínimo es API 19 con GLES2. El SDK local y las claves de firma no se incluyen. Lee `LEEME.md`, `REFERENCIAS_3_1.md` y `RENDIMIENTO_3_1.md` para instalación, recorrido y límites de las pruebas.
