# DreamCore 2.2 para Android Studio

Extrae y abre **DreamCore**, donde está `settings.gradle.kts`. SDK 34, JDK 17 o compatible, Gradle 8.7 / AGP 8.5.2 / Kotlin 1.9.24. Android mínimo API 21. versionCode 22 / versionName 2.2.

Android Studio crea local.properties. Compila con `gradlew.bat :app:assembleDebug` o Build APK(s). Para actualizar tu app manteniendo los datos, usa tu mismo identificador y clave de firma; no desinstales la app anterior. No se incluyen claves, SDK ni cachés.

En el inicio elige **Continuar partida**. En el juego: **Ajustes → Rutas y destinos** permite visitar la isla y la vista previa de ojos, además de las rutas anteriores. Nueva partida reemplaza el progreso solo tras confirmarlo. Consulta **DETALLES_2_2.md** y **VALIDACION.json**.
